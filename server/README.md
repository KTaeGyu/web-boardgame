# 게임 서버

방과 판이 사는 곳. Socket.IO 하나로 모든 통신을 받고, **상태는 전부 이 프로세스의 메모리**에 있다.
데이터베이스가 없다 — 방보다 오래 사는 데이터가 하나도 없다.

> 전체 그림과 게임 규칙은 [뿌리 README](../README.md) 를 먼저 본다.

---

## 띄우기

**필요한 것** — Node **22.18 이상**. 빌드 단계가 없어서 `.ts` 를 그대로 실행한다.

### 할 일

**1. 저장소 뿌리에서 설치한다** — 이 폴더가 아니라 뿌리다

```bash
cd ..           # 저장소 뿌리
npm install
```

**2. 띄운다**

```bash
npm run dev:server      # 뿌리에서. 코드가 바뀌면 알아서 다시 뜬다
```

**3. 살아 있는지 본다**

```bash
curl localhost:3001/healthz     # {"ok":true,"rooms":0}
```

> **주의 — 뿌리에서 설치해야 한다.**
> 이 폴더만 따로 설치하면 `@the-gang/shared` 가 이어지지 않는다.
> 작업공간(npm workspaces)이 뿌리의 `node_modules` 안에 심볼릭 링크를 만들어 주고,
> Node 가 그 링크를 실제 경로로 풀어 읽기 때문에 타입 제거가 통한다.
> 링크가 아니라 복사본이면 `node_modules` 안의 파일로 보여 거부당한다.

> **주의 — 다시 띄우면 열려 있던 방이 전부 사라진다.**
> 사람이 게임 중일 수 있다. 다시 띄우기 전에 알리거나 판이 끝나기를 기다린다.

## 환경변수

전부 없어도 뜬다. 없을 때의 값이 개발용으로 맞춰져 있다.

| 이름 | 기본값 | 무엇 |
|------|--------|------|
| `PORT` | `3001` | 배포처(Render)가 넣어준다 |
| `CORS_ORIGINS` | `http://localhost:5173` | 화면이 어디에 있는가. 콤마로 여럿. `*.vercel.app` 처럼 접미사로 열 수 있고, `*` 하나면 전체 허용 |
| `MAX_CONNECTIONS` | `40` | 동시 접속 한도 |
| `MAX_ROOMS` | `8` | 동시에 열려 있을 수 있는 방 |

한도는 **게임 규칙이 아니라 운영 한도**다. 무료 요금제의 이용량을 넘기지 않으려는 값이라
환경변수로 조절한다. 한도에 걸린 사람에게는 `server:full` 로 이유를 먼저 보내고 끊는다.

### 시간에 관한 값 (코드 안)

| 값 | 어디 | 무엇 |
|----|------|------|
| 10분 | `rooms.ts` `DISCONNECT_GRACE_MS` | 끊긴 사람의 자리를 지켜주는 시간 |
| 30분 | `config.ts` `IDLE_ROOM_MS` | 아무 움직임 없는 방을 치우는 시간 |
| 5초 | `config.ts` `SWEEP_INTERVAL_MS` | 유예 넘긴 자리를 치우러 도는 주기 |

**10분과 30분은 다른 이야기다.** 앞은 「연결이 살아 있는가」, 뒤는 「사람이 실제로 하고 있는가」다.

## HTTP 로 여는 것

소켓이 본업이라 HTTP 는 하나뿐이다.

| 경로 | 응답 | 쓰임 |
|------|------|------|
| `GET /healthz` | `{"ok":true,"rooms":<열린 방 수>}` | 배포처의 상태 확인. 잠든 무료 인스턴스를 깨우는 데도 쓴다 |

그 밖의 경로는 404 와 함께 「여기는 게임 서버입니다」를 돌려준다.

## 주고받는 것

계약은 [`shared/src/protocol.ts`](../shared/src/protocol.ts) 한 곳에 있다. 서버와 화면이 같은
파일을 보므로, 한쪽만 고치면 타입 검사에서 걸린다.

응답은 예외가 아니라 **값**으로 온다(`Result<T>`). 화면이 사유별로 다르게 안내할 수 있게 하려는 것이다.

### 화면 → 서버

| 이벤트 | 무엇 |
|--------|------|
| `room:create` / `room:join` / `room:leave` | 방에 들고 난다. 이미 자리가 있으면 입장이 아니라 **재접속**으로 처리된다 |
| `room:list` / `rooms:watch` | 방 목록. 목록 화면에 머무는 동안만 갱신을 받는다 |
| `room:settings` | 방장이 설정을 바꾼다 |
| `game:start` | 방장이 판을 연다 |
| `game:take` | 토큰을 집는다. 중앙에 있든 남이 쥐고 있든 같은 요청이다 |
| `game:ready` | 이 라운드 확정. 전원이 눌러야 넘어간다 |
| `game:continue` | 쇼다운을 보고 다음 판으로. 모두가 눌러야 넘어간다 |
| `game:rematch` | 재경기. 한 명이라도 거절하면 방이 닫힌다 |
| `game:toLobby` | 방장이 판을 접고 모두를 대기실로. 방은 남는다 |
| `game:setupCard` | 딜 직후 다 같이 하는 단계에서 내 몫을 마친다 |
| `game:discard` | 한 장 더 받은 뒤 버릴 카드를 고른다 |
| `game:scanVote` | 스캔에 답한다. 접속 중인 전원이 같은 답이면 확정 |
| `game:useSpecialist` | 해결사 카드를 쓴다 |

### 서버 → 화면

| 이벤트 | 누구에게 | 무엇 |
|--------|----------|------|
| `game:state` | 방 전체 | 모두가 보는 상태. **누구의 홀카드도 없다** |
| `game:hand` | 그 사람만 | 내 카드. 판이 바뀌거나 재접속하면 다시 온다 |
| `game:note` | 그 사람만 | 카드가 나에게만 알려준 것 (「정보원」으로 본 남의 카드 등) |
| `room:updated` / `room:closed` | 방 전체 | 방 상태와 닫힌 사유 |
| `rooms:changed` | 목록 구독자 | 방 목록이 바뀜 |
| `game:aborted` | 방 전체 | 사람이 빠져 판을 이어갈 수 없게 됨 |
| `server:full` | 그 사람만 | 한도 초과. 곧 끊긴다 |

> **은닉 정보의 통로는 하나로 묶여 있다.**
> 공개 상태(`game:state`)에는 쇼다운 전까지 홀카드가 들어가지 않는다 — 본인 것조차 없다.
> 스캔 중 지목된 사람의 카드도 답이 정해질 때까지 서버 밖으로 나가지 않는다.
> 미리 보내고 화면에서만 가리면 통신을 열어보는 것으로 답을 안다.

## 파일 지도

각 파일이 **무엇을 모르는지**가 경계다.

| 파일 | 무엇을 하나 | 무엇을 모르나 |
|------|------------|--------------|
| `app.ts` | HTTP + Socket.IO 를 세운다. `listen` 과 분리돼 있어 테스트가 임의 포트로 띄웠다 닫는다 | 게임 규칙 |
| `index.ts` | 실제로 포트를 연다. 배포 교체(SIGTERM)를 받아 조용히 닫는다 | — |
| `config.ts` | 환경변수와 한도 | — |
| `socket.ts` | **배선만.** 누가 무엇을 듣고 누구에게 보내는지 | 규칙의 속내 |
| `rooms.ts` | 방·자리·방장 승계·재접속 유예 | 소켓도 시계도 모른다. 시간을 주입받아 **타이머 없이** 테스트한다 |
| `game.ts` | 한 판의 진행과 **걸린 카드가 무엇을 하는가** | 소켓 |
| `extras.ts` | **어느 판에 무엇이 걸리는가** (모드별 뽑기·배치) | 카드의 효과 |
| `ids.ts` | 방 코드 4자. `0/O`, `1/I/L` 을 뺐다 — 전화로 불러줄 수 있어야 한다 | — |

**`game.ts` 와 `extras.ts` 를 갈라둔 이유** — 「카드가 무엇을 하는가」와 「어느 판에 걸리는가」는
서로 다른 규칙이다. 붙여두면 한쪽을 고칠 때 다른 쪽이 함께 흔들려 각각 검증할 수 없다.

## 테스트

```bash
npm test                                  # 뿌리에서. shared 까지 함께
node --test "test/**/*.test.ts"           # 이 폴더만
```

| 파일 | 무엇을 지키나 |
|------|--------------|
| `game.test.ts` | 판의 진행과 카드 20장의 효과 |
| `extras.test.ts` | 모드별로 어느 판에 무엇이 걸리는가 |
| `rooms.test.ts` | 자리·방장 승계·유예. 시계를 주입해 기다리지 않는다 |
| `socket.test.ts` / `gameSocket.test.ts` | 배선. 누가 무엇을 받는가 |
| `limits.test.ts` / `capacity.test.ts` | 한도와 방치 정리 |
| `rematch.test.ts` | 재경기와 방 닫힘 |

> **주의 — 소켓 테스트를 「다음 이벤트 하나」로 기다리지 않는다.**
> 직전 동작이 만든 브로드캐스트를 잘못 집는다. 조건으로 기다리거나(`until`),
> 각자가 받은 상태를 모아 두고 되짚는다(`waitState`). 같은 실수를 두 번 했다.
