## 사진에서 읽은 얼굴

사진 열 장이 `C:\Users\user\Downloads\1.png`~`10.png` 에 있다.
아래는 **그 사진들을 직접 보고 옮긴 것**이고, 그림의 근거는 이것 하나다.

### 얼굴형
- **긴 계란형에 완만한 사각턱.** 세로가 길고 폭은 보통 — 둥글거나 통통하면 안 된다
- 광대는 앞으로 도드라지지 않고 **옆으로 완만하게 퍼진다.** 웃으면 볼살이 올라온다
- 아래턱 각은 뚜렷하지 않지만 직선적이고, **턱끝은 좁고 둥글게** 마무리된다
- 이마가 **넓고 세로로 길다.** 헤어라인이 양옆으로 살짝 물러난 M자 기미가 있다
- 웃을 때 **한쪽 입꼬리가 더 올라가는** 좌우 비대칭이 있다

### 눈·코·입·귀
- **눈** — 홑꺼풀 계열의 **가늘고 긴 눈**. 동그랗지 않다. 눈 사이가 넓고
  **눈꼬리가 살짝 처져** 순한 인상이다. 웃으면 거의 실선으로 감긴다.
  눈밑 애교살이 도톰하고 다크서클이 옅게 있다
- **눈썹** — **굵고 짙은 일자형.** 산이 거의 없고 **눈과의 간격이 좁다**
- **코** — 콧부리가 낮고 콧대는 **완만하게 곧다.** 코끝은 **둥글고 살짝 두툼**하며
  아래로 처지지 않는다. 콧볼은 중간~약간 넓은 폭
- **입** — 중간 크기. **윗입술이 얇고 아랫입술이 도톰하다.** 인중이 뚜렷하다
- **귀** — 대부분 머리에 덮여 안 보인다. 중간 크기에 머리에 붙은 편

### 머리
- **검정색, 숱 많고 굵다.** 곱슬은 아니고 **자연스러운 굵은 웨이브** — 봉우리가 아니라
  잔 물결이다
- 길이는 **미디엄.** 옆·뒤는 정리돼 있고 **윗머리에 볼륨이 몰린다**
- **가르마를 타 옆으로 넘긴 것이 기본**이고 이마가 절반쯤 드러난다.
  가르마는 모양이 아니라 **갈라진 «선»** 이다
- 컨디션에 따라 편차가 크다 — 정리된 날은 가르마, 안 만진 날은 앞머리가 이마를 덮는다
- 구레나룻은 짧고 얇다

### 수염·안경·그 밖
- **안경 없음** — 열 장 전부
- **수염** — 기본은 면도 상태인데 **인중과 턱끝 주변에 옅은 잔수염 자국**이 자주 보인다.
  기른 컷은 없다. 「연한데 눈에 띈다」가 이 사람의 표시다
- **흉터·점** — 식별되는 것 없음
- **피부** — 유분기가 있어 이마·코에 하이라이트가 잘 생기고 볼에 옅은 홍조
- **옷** — 열 장 중 아홉이 **검정 티**
- **체격** — 목이 굵고 어깨가 넓어 얼굴이 상대적으로 작아 보인다

### 셋만 남기면
① 눈꼬리 처진 **가늘고 긴 홑꺼풀 눈** ② **굵은 일자 눈썹 + 넓고 긴 이마**
③ **숱 많은 검은 웨이브에 가르마**. 이 셋이 인상의 대부분을 잡는다.

## 그림이 지켜야 할 어법

다른 아바타 아홉 장이 이미 정해 놓은 규칙이다 — `web/public/avatars/*.svg` 를 본다.

- **64×64 viewBox**, 얼굴은 둥근 상자, 테두리 `#3b3222` 3px
- **눈 둘과 입 하나.** 코를 그린 아바타는 하나도 없다
- 실루엣을 상자 밖으로 내보내는 것이 허용된다(고양이 귀, 드라큘라 망토)
- 색은 있던 판에서 고른다 — 살구색 `#efd3ad` · 머리 `#2e2620` · 선 `#3b3222`

## 30px 이라는 제약

대기실 아바타는 **30px** 이다. 그 크기에서 읽히는 표시는 대여섯 개가 한계이고,
가르마 선·수염 음영 같은 것은 거의 사라진다. **큰 화면(76px)과 작은 화면 중
어느 쪽을 살릴지가 매번 갈림길**이다.

## 갈림길에서 고른 것 (2026-09-08)

- **검정 티.** 넥타이가 30px 에서 더 세지만 사진 9:1 을 따랐다. 머리와 티가 둘 다
  검정이라 붙어 보이는 것은 **목을 한 톤 어둡게**(`#dfb88e`) 넣어 갈랐고,
  티는 머리(`#2e2620`)와 미세하게 다른 판의 색(`#2b2b33`)을 썼다
- **씩 웃음을 넣었다.** 입 오른쪽 끝만 2 올라간다 — 다른 아홉 장은 전부 좌우 대칭
  곡선이라 이 한 장만 어법에서 벗어난다
- **수염은 옅은 음영.** 인중과 턱끝에 불투명도 0.1 언저리의 면 둘. 76px 에서만 산다

### 그리면서 갈린 것

- **상자를 정사각으로 두면 누구를 그려도 같은 얼굴이 된다.** 이 한 장만 폭 35 ×
  세로 41 의 계란형이고, 나머지 아홉의 `rx 9` 정사각과 다르다
- **눈을 아몬드 «채움»으로 그리면 감긴 눈으로 읽힌다.** 눕힌 타원(rx 4.6 · ry 2)을
  ±8° 돌려 눈꼬리를 내렸다
- **헤어라인이 눈썹보다 6 위에서 끝나야 이마가 남는다.** 옆머리를 눈높이까지
  내렸더니 곧장 헬멧이 됐다

## 확인하는 법

그림만 볼 때는 상점까지 갈 것 없이 정적 서버 하나면 된다.

```bash
# ▶ 내 PC
cd 개인프로젝트/the-gang/web/public
python -m http.server 5211 --bind 127.0.0.1
# http://127.0.0.1:5211/avatars/insider.svg
```

세 크기(76 · 48 · 30)로 나란히 놓고 본다. 브라우저가 SVG 를 캐시하므로
고칠 때마다 주소 끝에 `?v=<숫자>` 를 바꿔 붙인다.

상점·대기실에서 보려면 로컬을 **실계정 저장소(Contentful)를 물지 않게** 띄운다.

```bash
# ▶ 내 PC
cd 개인프로젝트/the-gang
CONTENTFUL_SPACE_ID= CONTENTFUL_MANAGEMENT_TOKEN= PORT=3099 \
  CORS_ORIGINS=http://localhost:5198 node server/src/index.ts

cd web && VITE_SOCKET_URL=http://localhost:3099 npx vite build \
  && npx vite preview --port 5198 --strictPort
```

**선물받은 사람의 화면**을 보려면 `loadAll()` 이 `cosmetics.owned` 에 `"insider"` 가
든 계정을 돌려주게 한다. 계정 줄의 열쇠는 `passwordSalt`·`passwordHash`
(`salt`·`hash` 가 아니다), 해시는 `scryptSync(password, salt, 32).toString('hex')`.
