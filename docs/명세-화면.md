# 화면 명세 — 어느 화면에 무엇이 있나

화면 아홉과 그 안의 조각들을 적은 표다. **무엇을 할 수 있는가**는
`docs/명세-기능.md` 가 짝이고, **왜 그렇게 만들었나**는 `README.md` 「정해진 것」에 있다.

기준일 2026-09-10.

---

## 화면 지도

```
  /                 첫 화면 ─┬─ /login ──┐
                             ├─ /signup ─┤
                             └─ /guest ──┴─→ /rooms ─┬─→ /rooms/:code (대기실)
                                                     │      └─→ /rooms/:code/game (판)
                                                     ├─→ /rooms/:code/watch (관전)
                                                     ├─→ /looks (상점)
                                                     └─→ /history (대전기록)

  «혼자 해보기» 는 첫 화면에서 곧바로 /rooms/LOCAL/game 으로 — 대기실을 거치지 않는다.
  없는 주소는 전부 / 로 되돌린다.
```

| 주소 | 화면 | 누가 보나 |
|---|---|---|
| `/` | 첫 화면 | 전부 |
| `/login` · `/signup` · `/guest` | 들어오는 길 셋 | 아직 안 들어온 사람 |
| `/rooms` | 방 목록(로비) | 전부 |
| `/rooms/:code` | 대기실 | 그 방의 사람·관전자 |
| `/rooms/:code/game` | 판 | 자리에 앉은 사람 |
| `/rooms/:code/watch` | 판 (관전) | 자리 없이 보는 사람 |
| `/looks` | 상점 | 로그인한 사람 |
| `/history` | 대전기록 | 로그인한 사람 |

## 모든 화면에 있는 것

- **오른쪽 위 도구 줄**(`.tools`) — 제보 · 소리 · 밀도 · 테마 · 족보표 다섯.
  족보표는 판을 보면서도 열 수 있어야 해서 여기 산다
- **서버 덮개**(`ServerGate`) — 서버가 자고 있을 때. **어디에 있느냐로 갈린다**:
  판 안에서는 한 줄만 남기고(끊겨도 테이블은 봐야 한다), 그 밖에서는 화면을 덮는다
- **접속 한도 화면** — 100명을 넘기면 연결이 끊기기 전에 이유만 남긴다

## 1. 첫 화면 `/`

| | 안 들어온 사람 | 로그인한 사람 |
|---|---|---|
| 가운데 | 「로그인」 · 「게스트로 하기」 | 이름 · 전적(`3승 2패`) · 로그아웃 |
| 아래 | | 「방 찾기」 · 「방 만들기」 |
| 맨 아래 | **「혼자 해보기 — 봇 2명과 연습」** (누구에게나) | 같음 |

- 제목 `THE GANG` 과 한 줄 소개 「말하지 않고 맞추는 협력 포커」
- **연습은 이름을 묻지 않는다** — 쓰던 이름이 있으면 그것, 없으면 「나」로 곧바로 시작한다
- 서버가 자고 있으면 「방 찾기·방 만들기」만 잠긴다. 연습은 열린다

## 2. 들어오는 길 셋

한 화면이 칸을 다 받던 것을 갈랐다 — 각 화면이 **자기 칸만** 든다.

| 화면 | 칸 | 끝나면 |
|---|---|---|
| `/login` | 이메일 · 비밀번호 | 첫 화면으로 (로그인 상태) |
| `/signup` | 이메일 · 비밀번호(4~64) · 닉네임(≤12) | 첫 화면으로 |
| `/guest` | 닉네임 | 첫 화면으로 |

## 3. 방 목록 `/rooms`

- **머리** — 「열려 있는 방」, 지금 몇 명이 붙어 있고 방이 몇인지(`lobby:stats`)
- **줄마다** — 방 번호 · 방장 이름 · 인원 `3/6`(그중 자리 비움 수) · 관전 `1/5` · 상태 배지.
  **인원은 접속 수가 아니라 «자리» 수다** — 끊긴 자리는 유예 동안 지켜져 남이 앉을 수
  없으므로, 들어갈 수 있는지를 정하는 수와 같은 수여야 한다
  - **게임 중인 방**은 「게임 중 · 관전」으로 뜨고, 누르면 **관전으로** 들어간다(물음창 한 번)
  - **내 자리가 남아 있는 방**은 정원이 차도 잠기지 않는다 — 서버가 정원보다 재접속을 먼저 본다
- **옆길 둘** — 「상점」(`/looks`) · 「대전기록」(`/history`). 로그인한 사람에게만 뜻이 있다
- 방이 닫혀 밀려온 경우 그 까닭이 위에 한 줄로 남는다(「재경기를 원하지 않는 사람이…」)

## 4. 대기실 `/rooms/:code`

두 칸으로 선다(721px↑). 좁으면 위아래로 쌓인다.

### 왼쪽 — 사람

- **참여자 목록** — 차림(아바타·배경·이펙트) · 이름 · 「방장」 · 「자리 비움」
  - 이름 옆 **말풍선 자리는 늘 비워 둔다** — 감정이 올 때마다 칸이 생기면 줄이 흔들린다
  - 내보내기(×)는 방장에게만. 자리를 비운 방장은 앉은 누구나 넘겨받을 수 있다
- **관전 목록** — `관전 1/5`. 자리와 같은 목록에 두지 않는다(인원수가 헷갈린다)

### 오른쪽 — 게임 설정 (방장만 만진다)

순서대로: **포커 방식 → 진행 방식 → (직접 고르기면) 금고·경보 → 세 묶음 → 자리**

- 포커 방식·진행 방식은 **펼치는 목록**(`PickList`). 닫혀 있으면 한 줄, 펼치면 이름만
  서고 설명은 짚을 때 뜬다. 목록은 **화면에 띄운다**(fixed) — 카드 안에 두면 잘리고
  카드에 스크롤이 생긴다
- **접이식 묶음 셋**(2026-09-10) — 「도전자 카드」 · 「무작위 도전자」 · 「해결사 배치」.
  접힌 채로도 머리에 지금 값이 남는다(`2장 고름` · `판마다 2장 · 1장 뺌` · `3판`).
  방장이 아니면 기본으로 접혀 있다
- 설명은 **짚을 때만** 뜬다 — 마우스는 올리면, 손가락은 누르면(`useCardTip`)

### 발밑

- 「게임 시작」(방장) · 「나가기」 · 오른쪽 끝에 **감정표현**과 **대화** 단추
- 못 시작하는 까닭은 그 위에 한 줄로: 3명 미만 · 누가 끊겨 있음 · 직접 고르기인데 카드 0장

## 5. 판 `/rooms/:code/game`

### 위에서 아래로

| 자리 | 무엇 |
|---|---|
| **게임 바** | 금고·경보 표시 · 몇 번째 판 · `2라운드 · 플롭` · (관전이면 「관전 중」) · 나가기 |
| **알림**(toasts) | 방금 나에게 벌어진 일. 지나가면 그만 — 눌러서·밀어서 닫는다 |
| **공개 안내**(announcements) | 판에 남는 기록. 알림과 층위가 다르다 |
| **남의 자리** | 카드 뒷면 · 이름 · 라운드별 토큰 이력. 감정표현이 자리 위로 뜬다 |
| **테이블** | 공용 카드(방식마다 모양이 다르다) · 가운데 토큰 무더기 |
| **양옆**(1024px↑) | 이번 판에 걸린 도전자 · 해결사 카드 |
| **내 자리** | 내 손패 · 이름 · 「확정」 · 내 토큰 |
| **확정 바**(좁은 화면) | 화면 아래 붙박이 |

- **남의 카드는 그리지 않는다.** 몇 장 쥐고 있는지만 보인다 — 공개되는 두 순간(스캔·쇼다운)은
  각각 제 창이 화면을 덮고 필요한 카드를 그 안에 다시 그린다
- 좁은 화면에는 **「칩만 모아 보기」** 전환이 있다 — 카드를 접고 토큰 이력만 두 줄로 모은다
- 토큰은 **누르면 날아간다**. 나간 자리는 같은 크기의 빈 구멍으로 남는다(옆의 것이 안 밀린다)

### 화면을 덮는 창 넷

| 창 | 언제 | 사람 줄 |
|---|---|---|
| **카드 고르기**(`SetupStep`) | 조율가·사기꾼·해커·잭이 걸린 판의 딜 직후 | 없다 (「○○님을 기다리는 중…」) |
| **스캔**(`ScanVote`) | 마지막 사람 공개 전 | 있다 — 전원의 토큰 이력과 표 |
| **해결사 쓰기**(`SpecialistUse`) | 걸린 판에서 누를 때 | 투표 |
| **결과**(`Showdown`) | 쇼다운 | 있다 — 공개 순서대로 |

**전원이 보는 창 위에서도 감정표현이 보인다**(2026-09-10) — 사람 줄이 있는 창은 그 줄 위에,
없는 창은 화면 층에 이름과 함께 뜬다. 대화·감정표현 단추는 창 위에 서 있어 언제든 눌린다.

### 결과 창

- 성공·실패 문구 · 공용 카드 · 공개 줄(토큰 · 이름 · 라운드 이력 · 카드 · 족보)
- 「핸드 보기 ↔ 조합 보기」 전환. 짚으면 그 사람이 쓴 다섯 장이 밝혀진다
- 아래: **「다음 금고로 (2/3)」** 또는 게임이 끝났으면 **「재경기 제안」 · 「방 나가기」**
- 관전자에게는 세는 것만 보이고 누를 수는 없다

## 6. 관전 `/rooms/:code/watch`

판과 **같은 화면**이되:

- 내 자리·확정 바·해결사 쓰기 단추가 없다. 「관전 중」이 게임 바에 붙는다
- 손패가 오지 않는다. 대화에는 「관전」 표시가 붙는다
- 아래가 비어 대화·감정표현 단추가 바닥으로 내려온다
- 판이 끝나면 **관전인 채로 대기실로**(`?watch=1`). 방이 닫히면 방 목록으로

## 7. 상점 `/looks`

- 넓은 화면(721px↑)은 **두 칸** — 왼쪽에 지금 차림·골드·안내가 붙박이고(sticky),
  오른쪽에 슬롯 넷이 차례로 선다
- **슬롯 넷**: 아바타 · 프로필 배경 · 이펙트 · 배너
- 가진 것은 눌러서 **바로 장착**, 안 가진 것은 **물음창 한 번**(치른 뒤의 잔액을 보여준다)
- 못 사는 것(`grantOnly`)은 목록에 아예 안 선다 — 가진 사람에게만 보인다

## 8. 대전기록 `/history`

- 이름 · 끝을 본 판 수 · 「이김 / 짐」 둘. **순위표가 아니다** — 남과 견주는 자리가
  아니라 스스로 보는 자리다
- 세는 자리는 계정 하나뿐이다. 도중에 나간 판은 승도 패도 아니라 아무 줄도 남기지 않는다

## 9. 어디에나 붙는 대화·감정표현

- **대화 단추**(오른쪽 아래) — 안 읽은 수가 배지로. 누르면 창이 단추 **왼쪽**에 선다
  (위로 세우면 화면이 낮을 때 판을 세로로 가로지른다)
- **새 말 한 줄**(2026-09-10) — 접혀 있을 때 대화 단추 **위에 말풍선**으로 잠깐 붙는다.
  꼬리가 단추를 가리킨다. 예전에는 단추 왼쪽에 알약으로 서서 감정표현 단추를 가렸다
- **감정표현 단추** — 대화 단추 왼쪽. 펼치면 목록, 하나 고르면 보내고 접힌다
- 좁은 화면에서는 셋이 함께 확정 바 위로 올라간다

## 화면이 갈리는 선

| 선 | 무엇이 바뀌나 |
|---|---|
| **640px 아래** | 자리는 옆으로 미는 줄 · 확정 바가 바닥에 붙박이 · 덮개는 아래에서 올라오는 시트 · 「칩만 모아 보기」 |
| **721px 위** | 대기실이 두 칸(카드가 각자 스크롤) · 상점이 두 칸 · 대화가 발밑 줄의 한 칸 |
| **1024px 위** | 테이블 양옆에 도전자·해결사 카드가 선다 |

높이는 `--app-height` 로 잰다 — 모바일 브라우저의 주소창이 오르내려도 화면이 튀지 않게.
