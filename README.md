# The Gang (웹)

보드게임 **더 갱**(협력 포커)의 웹 구현. 개인 프로젝트.

원작: 3~6인 협력 게임. 텍사스 홀덤과 같은 진행이지만 베팅 대신 **토큰**을 집어
"내 손패가 상대적으로 몇 번째로 센가"를 선언한다. 카드 이야기는 금지 —
토큰이 유일한 언어다. 마지막 라운드 토큰 순서대로 공개해 약→강 순서가 맞으면
금고 하나를 열고, 틀리면 경보가 울린다. 금고 3개면 승리, 경보 3개면 패배.

## 구조

| 폴더 | 역할 | 배포 |
|------|------|------|
| `shared/` | 카드·핸드 평가·쇼다운 판정. 서버와 웹이 함께 쓴다 | — |
| `server/` | Socket.IO 게임 서버. 상태는 전부 메모리 | Render |
| `web/` | React 클라이언트 (Vite) | Vercel |

DB는 쓰지 않는다. 방이 살아있는 동안만 상태가 필요하고 영속시킬 것이 없다.

## 실행

```bash
npm install
npm test              # 규칙 · 방 · 소켓 배선 테스트
npm run typecheck
npm run dev:server    # 소켓 서버 (기본 :3001)
npm run dev:web       # 화면 (http://localhost:5173)
```

둘 다 띄워야 동작한다. 화면 환경변수는 `web/.env.example` 참고 (`VITE_SOCKET_URL`).

서버 환경변수: `PORT`(Render 가 넣어준다), `CORS_ORIGINS`(콤마 구분, `*.vercel.app` 같은
접미사 허용 가능, `*` 면 전체 허용).

Node 22.18+ 필요. `.ts` 를 빌드 없이 그대로 실행하므로 `shared` 에는 빌드 단계가 없다.

## 정해진 것

**방 식별자는 짧은 코드 문자열이다.** 방마다 포트를 여는 방식은 불가능하다 —
Render 는 인스턴스당 포트를 하나만 열어준다. Socket.IO 의 room 으로 한 포트 위에서 나눈다.

**플레이어 식별자는 닉네임이 아니다.** 브라우저 `sessionStorage` 의 랜덤 id 가
정체성이고 닉네임은 표시용이다. 동명이인이 서로를 덮어쓰지 않고, 새로고침해도
자기 자리로 돌아온다.

**토큰 잠금은 토큰 단위다.** 애니메이션이 도는 동안 그 토큰만 잠근다.
전역으로 잠그면 여러 명이 활발히 뺏을 때 서로의 입력을 계속 먹는다.
같은 토큰을 노린 동시 요청은 Node 가 단일 스레드라 도착 순서가 곧 정답이다.

**화면은 서버 확정 후에 움직인다.** 낙관적 UI 는 뺏기가 잦은 이 게임에서
되돌리는 일이 많아 화면이 튄다.

**게임 중 이탈은 30초 유예.** 끊긴 사람의 자리는 남기고 흐리게 표시한다.
돌아오면 그대로 복구하고, 넘기면 자리를 비운다. 방장이 사라지면 남은 사람 중
가장 먼저 들어온 사람에게 넘어가되 접속 중인 사람을 우선한다.
스스로 「나가기」를 누른 것은 끊김과 달라서 유예 없이 즉시 자리가 빈다.

**방 주소가 곧 방이다.** `/rooms/{코드}` 를 새로고침하거나 남에게 링크로 보내도
그대로 들어가진다. 정적 호스팅에서는 이 경로가 404 가 나므로 `web/vercel.json` 이
모든 경로를 index.html 로 돌린다.

**토큰 잠금은 토큰 단위이고 화면 애니메이션과 같은 길이(0.5초)다.** 그동안 그 토큰만
잠긴다. 내가 쥐고 있다 중앙으로 돌아가는 토큰도 날아가는 동안 함께 잠근다 —
비행 중인 토큰을 낚아채면 화면이 무엇을 보여줘야 할지 알 수 없다.
잠금은 시간이 지나면 저절로 풀리지만 아무도 그 사실을 모르므로, 서버가 풀리는 시점에
상태를 한 번 더 보낸다.

**은닉 정보는 공개 상태에 담기지 않는다.** `GameView` 에는 쇼다운 전까지 누구의
홀카드도 없다 — 본인 것조차 없다. 내 카드는 `game:hand` 로 나에게만 따로 간다.
새로고침해서 돌아와도 같은 카드가 다시 온다.

**판이 도는 중에 누가 나가면 판을 접는다.** 라운드 종료 조건이 「전원이 확정」이라
한 명이 빠지면 영원히 끝나지 않는다. 끊긴 것은 나간 것이 아니므로 30초를 기다리고,
유예를 넘겨야 판을 접고 대기실로 되돌린다.

**쇼다운은 "같거나 강하면" 통과.** 완전히 같은 핸드(true tie)는 순서와 무관하게
정답이다. 등호를 허용하는 것만으로 자연스럽게 처리된다.

## 핸드 평가 메모

- 로열 스트레이트 플러시는 별도 족보가 아니라 A탑 스트레이트 플러시다.
- A 는 양끝에 붙는다. `AKQJT` 가 최강, 휠 `5432A` 가 최약이며 이때 탑은 5 다.
- 무늬에는 우열이 없다. 키커까지 같으면 진짜 동점이고, 그것이 룰북의 true tie 다.
- 평가 결과는 족보 이름이 아니라 사전식 비교가 가능한 숫자 배열(`score`)이다.
  우열뿐 아니라 "완전히 같음"까지 구분해야 하기 때문이다.
